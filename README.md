# DefSynUS: Real-time Patient-specific Intrahepatic Vessel Identification via Deformation-Aware CT-US Domain Adaptation

Beaudet K.-P., Velikova Y., El Hadramy S., Cattin P., Navab N., Verde J., Cotin S. — IJCARS submission (2026).

DefSynUS trains a patient-specific intrahepatic vessel identification model (MPV / LPV / RPV / HV) from preoperative CT alone, and deploys it on intraoperative ultrasound through CT→US domain adaptation. The pipeline integrates (i) deformation-aware volumetric augmentation, (ii) 2D reslicing of the deformed label map, (iii) physics-based differentiable US rendering ([LOTUS](https://arxiv.org/abs/2307.16021)), and (iv) unpaired image translation ([CUT](https://arxiv.org/abs/2007.15651)) feeding an Attention U-Net segmentation head.

> Code release: <https://github.com/Karl-Philippe/DefSynUS> — data CC BY 4.0 · code Apache-2.0.

## Method overview

Preoperative (training) phase:

1. CT → label map (TotalSegmentator + MPV/LPV/RPV/HV refinement).
2. **Deformation-aware augmentation** — sample smooth 3D displacement fields (per-axis amplitude ≤ ~42 mm, mean ~27 mm) and warp the label map via grid sampling.
3. **Reslicing** — MONAI `RandAffine` reslicing (tilt / rock / slide / small out-of-plane rotation) produces 2D label slices.
4. **Differentiable US rendering** — per-class acoustic parameters (α, Z, μ₀, μ₁, σ₀); end-to-end trainable.
5. **CUT** learns real → rendered translation from unpaired US; Attention U-Net segments vessel branches.

Intraoperative (inference) phase: real US → CUT generator → Attention U-Net → per-branch vessel overlay at ≥50 fps on an RTX 4070 Ti.

## Installation

```bash
conda env create -f environment.yml
conda activate defSynUS
```

Requires PyTorch 2.5.1, MONAI 1.3.0, CUDA-capable GPU.

## Data preparation

DefSynUS consumes two kinds of data:

1. **CT label maps** — generated by the [data_generation/](data_generation/) subpackage from a CT volume with per-branch vessel labels.
2. **Real ultrasound cohorts** — supplied manually under `datasets/`:
   - `datasets/trainA_500/` — unpaired real US, used by CUT's `trainA` side.
   - `datasets/GT_data_vessels_stopp_crit/{imgs,masks}/` — paired real-US + GT vessel masks for early-stopping.
   - `datasets/GT_data_vessels_testing_100/{imgs,masks}/` — paired real-US + GT vessel masks for held-out test.

### Generating deformed label maps

The pipeline stages are `deform → labels → warp → masks`. The optional `images` stage renders US PNGs for visual debugging — disabled by default because LOTUS renders US internally at training time.

```bash
# Phantom (rigid; skips deform by default, no deformation-aware aug)
python -m data_generation.generate_dataset --dataset phantom --config config/config_data_generation.yml

# Human (full deform → labels → warp → masks)
python -m data_generation.generate_dataset --dataset human --config config/config_data_generation.yml

# Add --no-skip-images to also produce rendered US PNGs
python -m data_generation.generate_dataset --dataset human --no-skip-images
```

Outputs land in `CT_label_maps_{dataset}/{labels,labels_warped,masks_warped}/`. Point `base_folder_data_path` / `labelmap_path` in the training config at that directory.

The `--dataset {phantom,human}` flag also selects the label-convention preset inside [models/us_rendering_model.py](models/us_rendering_model.py) via the `dataset_kind` hparam. Training configs set `dataset_kind` explicitly.

## Training

```bash
# Phantom (rigid / reslicing only, no deformation-aware aug)
python train.py -c config/config_run_us_multilabel_liver.yml

# Human patient (deformation-aware + reslicing)
python train.py -c config/config_run_end2end_vessels.yml
```

Training settings (from the paper): Adam with lr 1e-5, batch size 8, 10–200 epochs with early stopping (patience 5). Per-patient training completes in ≈2 h on an RTX 4070 Ti.

## Inference

```bash
python inference.py -c config/config_file.yml                    # inference only
python inference.py -c config/config_file.yml --compute_metrics  # + per-label precision/recall
```
